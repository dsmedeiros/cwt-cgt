# PRD: Phase 40 — Benchmark G (Second Positive Noisy Scaffold Benchmark)

## Overview

Integrate Phase 40 analysis from the CWT-CGT facelift package (v5.1) into the cwt-sim repository. Phase 40 adds **Benchmark G**, a four-node skew-ring scaffold benchmark that tests whether the accepted Phase 39 noisy loop-side rule transfers beyond benchmark C without refitting. This is the first multi-benchmark generalization test for the noisy lane.

## Motivation

The current repo has phases 16-39 fully integrated. The noisy loop-side rule has only been validated on benchmark C. Phase 40 tests rule transfer to a second distinct benchmark topology (Benchmark G), strengthening scaffold-level confidence that the rule is not a single-benchmark artifact.
