# PRD: Phase 41 — Pooled Positive Noisy Scaffold Rule Integration

## Overview

Integrate Phase 41 analysis from the CWT-CGT facelift package (v5.2) into the cwt-sim repository. Phase 41 derives a **single pooled positive-noisy scaffold rule** from the combined train rows of benchmarks C and G, then evaluates held-out families on both benchmarks without benchmark-specific refit. This is the first cross-benchmark pooled rule, strengthening the noisy scaffold from one-way transfer to a shared rule.

## Motivation

The repo has phases 16-40 integrated. Phase 40 proved one-way transfer from C to G. Phase 41 goes further: pooling train rows from both benchmarks to derive one shared rule, then evaluating held-out families from both benchmarks under that shared rule. This strengthens scaffold-level generalization.
