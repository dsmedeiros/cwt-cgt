## Current empirical status

- The analytic/executable layer supports the CGT metric/Wilson identities and their common sign convention. QP-1 is an `S²` sphere-chart Chern/flux calibration with periodic azimuth, collapsed polar boundaries, and a varying but open gap; it is not a torus band. The separate perturbed Qi–Wu–Zhang benchmark is the periodic-`T²` check.
- A local response-curvature surface law is conditional on first deriving an adiabatic/tangent local line functional for the concrete update. CGT-flux proportionality additionally requires response-curvature alignment and non-degenerate coupling/readout; its coefficient may be zero.
- A new internal proof program establishes `Q_c=integral B_c+O(1/N)` for a declared finite-dimensional uniformly contractive, smooth fixed-branch, update-then-sample class, including the complete on/zero interaction and the ordinary factor-two difference-in-differences. Generic equilibrium-reset scaled-loop error is `O(s/N+s^2/N)`; a stronger periodic/endpoint-flat rate requires a periodic orbit or matched corrector, C3 endpoint consistency, and a proved summation-by-parts cancellation. The separately scoped ODE corollary requires both a uniformly bounded frozen-branch inverse and a uniform branch-linearized driven-propagator bound, defines `Q=integral_0^T r dt`, and fixes equilibrium versus periodic/matched initialization, exact reversal, and endpoint accounting. Propagator decay alone does not supply the inverse; the program includes a scalar singular-J counterexample. This is not a derived continuous CWT limit.
- The same program proves an exact no-go theorem: any smooth local response one-form can be realized by a uniform contraction independently of a normalized projective state map. Thus smoothness, contraction, a gap, and a branch cannot imply `F_R^D=kappa Omega`; `Omega!=0` need not produce response, and response need not imply `Omega`. The executable C1-C8/P1 matrix and deliberately aligned three-dimensional oracle/positive implementation control are `PASS_INTERNAL_ANALYTIC` / `NO_EMPIRICAL_EVIDENCE`, not an independently measured response or external/physical confirmation.
- One narrow internal exception is now executable: the locked benchmark-C fixed-tick relaxation/current fixture derives `Q = integral B + O(1/m)` for the `discrete_cycle_sum_surrogate`, with the response calculated independently of its later geometric predictors. Its `F_R/Omega` versus `Q_anti/Phi_anti` comparison is only an algebraic 2D quotient/implementation-consistency check: any two nonzero 2-forms in 2D are pointwise proportional, so it has no independent CGT-predictive content. This selected discovery/analytic fixture is not independent empirical validation, physical transported charge, a preregistered holdout, external evidence, or a general CWT response proof.
