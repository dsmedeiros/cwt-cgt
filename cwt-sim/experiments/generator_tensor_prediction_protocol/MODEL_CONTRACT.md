# Generator-tensor prediction protocol

This isolated experiment is a response-sealed, source-first protocol for the
merged five-state loop-flux model. It does not import or execute a counted
response, FCS, oracle, or predecessor theorem lane.

The current source phase contains two cases:

- `N0_KRYLOV3_NO_GO` proves that the predeclared three-member Krylov family has
  no nonzero member whose predicted two-form is closed. Its classification is
  `NO_NONTRIVIAL_CLOSED_MEMBER / INELIGIBLE_NOT_CLOSED`.
- `P0_CONNECTION_GEOMETRY_ELIGIBILITY` proves only that a three-coefficient
  gauge-invariant connection family has an exact, well-conditioned input design
  at six frozen rational calibration points, two reserved whole-center
  confirmations, and one reserved oblique heldout point.

The connection family is

`Bhat_sigma = sigma * [k0/2*(u*dv-v*du) + k1*u*dp + k2*v*dp]`,

where `u` and `v` are the fixed-reference normalized real and imaginary Wilson
scalars and `p=Tr(rho^2)` is stationary purity. Therefore

`Fhat_sigma = sigma * [k0*du^dv + k1*du^dp + k2*dv^dp]`

is closed identically. The coefficients are not fitted in this source phase.
Flux-conjugate branches are recomputed exactly. The stationary-purity basis does
not obey the tempting fixed diagonal parity rule, so that rule is explicitly
refused and no unproved conjugation law for a future response is claimed.

Acceptance binds the complete exact N0 and P0 certificate payloads: centers,
families, component and derivative conventions, exact rows or basis matrices,
confirmation and heldout geometry, conjugation records, authorities, and
dispositions. Determinant-only or producer-boolean acceptance is forbidden.
The sigma-valued connection and curvature rules are executed for positive,
reversed, and zero orientations. A singular reviewed design is a refusal, not a
fallback rank label.

The source-only firewall covers every package Python file, this contract, and
the focused test with an exact ordered path/type/raw-hash inventory. Protected
roles use exact module-and-symbol import inventories plus explicit capability
allowlists. They reject predecessor or other-experiment imports, file and path
reads, process, environment, network, dynamic import, and reflective callable
recovery, including value binding or higher-order transport of a prohibited
callable. Path, stream, process, environment, and interactive Typer capabilities
are rejected as references as well as direct calls. The composition role's sole
Path and `sys.path` exception is the exact module-level
`sys.path.insert(0, str(Path(__file__).resolve().parents[2]))` bootstrap. The
focused-test role's sole `CliRunner` uses are the reviewed constructor assignment
and exact `status` and `verify-source` invocations. Constructed receiver aliases,
method chains, and module extraction are otherwise rejected. The firewall
authority may read bytes only through the verified `MATERIAL_FILES -> relative ->
_material_path(relative) -> path.read_bytes()` dataflow; arbitrary literal or
computed paths remain forbidden. Runtime membership requires an exact reviewed
material path, and every authority filesystem call is bound to the exact AST of
its reviewed inventory function, so shadowing, reassignment, or added metadata
access invalidates the gate. Reviewed AST fingerprints use a canonical syntax
tree domain that includes every semantic field and ignores only an empty
grammar-version compatibility field; they do not depend on `ast.dump` display
defaults or a Python minor version. The focused test may import only the reviewed
current symbols, pytest, and Typer's test runner and cannot directly read files,
import package-module re-exports, or import a predecessor response. Every role
has exact live-derived builtin reference and call sets; interactive, site,
process, and reflection builtins are refused, and `type`/`id` are restricted to
the reviewed strict-type and internal identity contexts. Controlled Path and
CLI-runner constructor symbols are permitted only as exact reviewed callees or
authority annotations; returning, aliasing, containing, or subclassing them is
forbidden. A CLI result's runner back-reference retains its controlled receiver
provenance, including when a controlled instance or result crosses a reviewed
function/lambda return or list, tuple, set, or dictionary container. Runtime
names, imported capability aliases, and the material-inventory roots are
immutable: assignment, deletion, argument shadowing, and global/nonlocal
rebinding are refused, including import aliases and every nested structural
pattern capture. The sole authority-root definitions and composition

enclosing syntax. At import, the firewall independently requires the resolved
`__file__`, `PACKAGE_DIR`, and `SIM_ROOT` relationship to equal the loaded
`firewall.py` path. Before its first filesystem read, the inventory entrypoint
also checks exact root types/relations plus literal material, role, membership,

and iterable/container expression forms preserve controlled receiver
provenance; controlled generator yield/send and method/descriptor return
channels are refused. The public arbitrary-text analyzer always returns
`UNREVIEWED_SOURCE_IDENTITY`; it accepts no caller digest, token, path identity,
or authority override. The exact-path disk scanner accepts only a reviewed
relative path and role, membership-checks the literal inventory, rejects

defense-in-depth. Dual reviewers externally bind the stable raw hashes, while
the later external Git-index
`SOURCE_LOCK.json` and staged audit are the publication authority; this source
