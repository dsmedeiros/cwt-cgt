# CWT-CGT Theory Hardened v43

The theory is now best understood as a **layered benchmarked framework** with four distinct layers:

1. a **coherent, branch-resolved passive core**,
2. an explicit **R4 branch-switching lane**,
3. an auxiliary **periodic/gapped topology lane**,
4. a **noisy scaffold lane** built from generator-derived local structure and tested on held-out loop families.

## What changed in this revision
This revision broadens the noisy scaffold rule again in two ways:

- it builds a **pooled four-positive noisy scaffold rule** across benchmarks **C, G, H, and I**, using train rows pooled across all four positive scaffold cases;
- it reruns the **stronger perturbation family** on benchmark **I** under that broadened pooled rule with **no stronger-family refit**.

## Current boundary
This remains **scaffold evidence**, not external empirical validation. The noisy layer is better supported than before, but it is still not a final microscopic theory.

## Current verdict
The noisy scaffold layer now supports a **shared pooled rule** across four positive scaffold benchmarks and still transfers to a stronger perturbation family on the non-ring benchmark.
