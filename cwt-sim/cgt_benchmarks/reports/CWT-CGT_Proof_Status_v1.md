## Bottom line

The named Benchmark D proof harness now instantiates the discrete uniform-contraction theorem for one authored five-state core open-system channel and geometry-blind `mean_position` readout. On its frozen D0 box it certifies exact global contraction `124/125`, a true full-rank linear-solve fixed branch, and nonzero response curvature. The authored stationary-probability geometry is not treated as a smooth projective branch; a separate channel-equivalent constant normalized reference has exact `Omega_bd=0`. This is only a constant-reference response-without-curvature no-go control, not CGT alignment support. Its status is `PASS_INTERNAL_ANALYTIC` / `NO_EMPIRICAL_EVIDENCE`; it is not the full scheduler, physical time, or an external result. The historical Phase10 entry script explicitly set `branch_steps=2`, which the tracked Benchmark-C JSON records with recommended `gamma=.2`; the current library default is 3 and the current analysis module is a recomputation implementation. Its explicit-config recomputation has a nonzero fixed residual and remains a finite-step surrogate. A separate Benchmark-D three-step diagnostic does not validate it.

The repository contains useful analytic identities and synthetic calibration machinery. A new internal proof program establishes a finite-dimensional uniform-contraction response theorem and an exact arbitrary-one-form realizability/no-go theorem; the earlier benchmark-C fixed-tick result is a narrow linear-contracting corollary. The no-go result proves that contraction and smoothness alone cannot make projective CGT curvature predict response curvature. These results are `PASS_INTERNAL_ANALYTIC` / `NO_EMPIRICAL_EVIDENCE` and do not prove the central empirical claim that CGT flux independently predicts a nonzero orientation-odd CWT readout on external observations. In the benchmark-C harness, "independent response" means that response is calculated without geometry/orientation inputs; it does not mean independent empirical validation. Its local `F_R/Omega` comparison has no predictive content because pointwise proportionality of nonzero 2-forms in 2D is algebraic. A metadata-only active-loop design template records stricter external confirmation requirements, including the distinction between generic equilibrium-reset and separately justified periodic/endpoint-flat remainder rates, but it is `BLOCKED_NO_SUBSTRATE`, has no outcome loader or confirmation command, and contributes no evidence. A post-hoc OEDI IEEE123 reconstruction is reproducible from a pinned official test-system source consistent with the archived vector, but it refutes rather than supports the old structural/sign-boundary interpretation and cannot prove the original run's source revision/parser. ## Provenance tiers

- **Tier A — analytic/executable:** equations are tied to implementation and focused tests recompute the result.
- **Tier B — internal synthetic:** a runner generates states/results from a declared synthetic benchmark; useful for construction and falsification, not external validation.
- **Tier C — static/adaptive summary:** checked-in JSON or a loader reproduces reported values without recomputing raw observations; descriptive only.
- **Tier D — provenance-locked retrospective external test-system reconstruction:** pinned public-source bytes, parser, checksums, and one-command reconstruction reproduce an archived vector after outcomes were known. This establishes present reproducibility only, not original historical provenance, field-observation status, prospective confirmation, independence, or theory support.
- **Tier E — unaudited derived external summary / endpoint metadata:** narrative/derived metrics or endpoint metadata without the raw payload, checksums, and one-command reproduction needed for an auditable result.
