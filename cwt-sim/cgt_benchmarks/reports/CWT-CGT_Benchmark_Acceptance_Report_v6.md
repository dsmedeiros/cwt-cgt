# CWT-CGT Benchmark Acceptance Report — v6

## Overall verdict

The project now supports a **qualified pass** for the hardened benchmark program.

That pass is qualified because different lanes are at different maturity levels.

## Coherent / passive lanes

- benchmark A: pass as null-like control
- benchmark B: pass as weak / patchy non-pump line benchmark
- benchmark C: pass as positive coherent signed-loop benchmark on trusted patches
- benchmark D: pass as null-like control
- benchmark F: pass as explicit R4 / branch-switching exclusion benchmark
- benchmark E: pass as legitimate auxiliary topology benchmark

## Noisy / mixed-state lane

- benchmark C: pass as the positive noisy benchmark **only in a local / patchwise sense**
- broader loop-family rerun: global fit weak, patchwise fits materially stronger
- A / B / D / F: prior control conclusions carried forward; not fully rerun in the Phase 12 targeted pass

## Interpretation

The acceptance outcome is therefore:

- the **benchmark architecture** is sound,
- the **coherent theory** is in reasonable shape for a toy-scaffold research program,
- the **noisy theory** needs a local susceptibility atlas before it should be treated as benchmark-wide.
